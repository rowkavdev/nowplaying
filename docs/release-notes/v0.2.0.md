First release you can install and set up without a terminal: a setup page, local Discord Rich Presence and hosted README cards, all on Windows.

## Breaking changes

None that need action. A config saved by v0.1.0 is upgraded automatically on first start (see Migration).

## Migration

- On start, NowPlaying migrates an older `config.json` to the current version. Before changing anything it copies the original to `config.json.backup-<time>` next to it.
- Media server sign-ins made through setup are kept in Windows Credential Manager, not in `config.json`.
- If you used v0.1.0 by hand-editing `config.json`, you can run setup instead. It starts from your installed config and keeps your other settings.

## Compatibility

- Windows, 64-bit (x64). macOS and Linux aren't supported yet (#215).
- Download the setup `.exe` or the portable `.zip`. Both are unsigned, so SmartScreen may warn: choose **More info**, then **Run anyway**. Check a download with `SHA256SUMS`, or with `gh attestation verify <file> --repo rowkavdev/nowplaying`.
- Updates are not automatic yet. To get a later 0.2.x, download and run the new installer. Your settings are kept.

## Security

- Media server credentials stay on your PC in Windows Credential Manager. They never go into config files, logs, diagnostics or the hosted card.
- Hosted cards only receive the display fields you allow in setup. [What leaves your PC](https://github.com/rowkavdev/nowplaying/blob/main/docs/hosted-upload.md) lists every field.
